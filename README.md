# Riza Shaikh — Java Backend Portfolio

A responsive portfolio built with plain HTML, CSS, and JavaScript. No build step or package installation is required.

## Pages
- `index.html` — portfolio and experience
- `ai-semantic-search.html` — Semantic Search case study with screenshots and evaluation PDF

Open `index.html` in a browser to start. Fonts load from Google Fonts with local fallbacks.
